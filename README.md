Контрольные вопросы

1. потому что имя компьютера хранится в системе, а программа просто запрашивает его у ОС.
2. ОС это посредник. программа не может сама напрямую залезть в память или процессор и поэтому просит данные у ОС.
3. это означает что ОС использует 64-битную архитектуру и способна работать с большим адресным пространством.
4. Environment.ProcessorCount показывает сколько логических процессоров видит программа. оно не обязательно должно совпадать с числом физ ядер.
5. вся оперативная память - это общий объём всей памяти вообще. а WorkingSet - это то, сколько занимает конкретно ваша программа.
6. потому что она берёт данные из системы. на разных компьютерах данные будут разные.
